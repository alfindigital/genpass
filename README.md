GenPass is a secure, fast, and user-friendly password generator that runs entirely in your browser. It generates strong, random passwords with full customization options - all without storing any data.

## 🚀 How to Deploy

### Option 1: Vercel (Recommended) - 3 clicks
```bash
1. Push code to GitHub
2. Import project to Vercel
3. Deploy (automatic from git push)
4. Done!
```

### Option 2: Any Hosting
```bash

# Upload dist/ folder to your hosting
```

2. Add Google Analytics tracking
3. Verify domain in Bing Webmaster
